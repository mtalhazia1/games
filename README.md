# Games

## Isla Nublar Expedition (`jurassic-world/`)

A first-person 3D dinosaur park you can walk around in, built with Three.js in a single HTML file.

**Play:** open `jurassic-world/index.html` in a browser (needs internet for the Three.js CDN).

- Walk the island, enter the breached T-Rex paddock and the raptor pen, climb the volcano.
- Goal: recover 10 pieces of amber and log all 7 species (T-Rex, Velociraptor, Brachiosaurus, Triceratops, Stegosaurus, Gallimimus, Pteranodon).
- Predators chase you inside their territory; sprint to escape.

Easy controls (made for young kids):

| Control | Desktop | Touch |
|---|---|---|
| Run (default speed) | ↑ (or W) | Left stick |
| Turn | ← → or mouse drag | Drag |
| Jump to next dinosaur | Enter / N, or number keys 1–7 | GO TO button |
| Super speed | Shift | — |
| Jump | Space | JUMP |
| Sound | M | Sound button |

## Mikey & JJ: Block Island (`mikey-and-jj/`)

A small Minecraft-style block island starring fan versions of Mikey (green turtle) and JJ (red hoodie). Single HTML file, Three.js.

**Play:** open `mikey-and-jj/index.html` in a browser (needs internet for the Three.js CDN).

- 64×64 island: Mikey's and JJ's houses, a mountain diamond mine, trees, beach and sea.
- Play as Mikey or JJ; the other one follows you, fights mobs and talks. Switch any time.
- Both characters speak out loud (browser text-to-speech, different voices) with speech bubbles.
- Mobs: zombies, skeletons (arrows), creepers (explode), spiders at night; pigs, cows, sheep, chickens by day.
- Break and build blocks, light TNT, day/night cycle, sound effects and music (all generated in the browser).
- Goal: find the 5 diamonds in the mine.

| Control | Desktop | Touch |
|---|---|---|
| Walk | W A S D / ↑ ↓ (← → turn) | Left stick |
| Look | Mouse | Drag |
| Hit / break | Left click or Q | HIT |
| Build | Right click or E | BUILD |
| Jump / swim | Space | JUMP |
| Pick block | 1–9 or wheel | Tap hotbar |
| Switch Mikey/JJ | Tab | SWAP |
| Make them talk | T | TALK |
| Camera / time / sound | V / N / M | VIEW |
